What the course is about

Algebra asks which rules are enough for a system to behave like arithmetic. You meet several systems: clock arithmetic (numbers that wrap around after m), the complex numbers, and vectors (arrows, lists of numbers, polynomials). For each one you ask the same questions: which pieces can I build from others, which pieces are redundant, and how many independent pieces do I need?

How to read a definition

  1. Say it in words. Find the plain-English idea before the symbols.
  2. Name the pieces. Which symbols are the objects, which are the rules, and which are the conditions?
  3. Work one example. Use small numbers you can check by hand.
  4. Break one example. Find a case that fails. The non-example shows what the definition rules out.

Worked examples

Each example shows the reasoning, not just the answer. Cover the steps and try them yourself first.

1 · Show that f(x) = 2x + 1 is a bijection from ℝ to ℝ

  1. Injective. Assume f(x) = f(y). Then 2x + 1 = 2y + 1, so 2x = 2y, so x = y.
  2. Surjective. Take any real y. Let x = (y − 1)/2, a real number. Then f(x) = 2 · (y − 1)/2 + 1 = y.
  3. Conclusion. Both properties hold, so f is bijective. The x found in step 2 is the inverse function evaluated at y.

2 · Is W = {(x, y, z) ∈ ℝ³ : x = 2y} a subspace?

  1. Zero. (0, 0, 0) satisfies 0 = 2 · 0, so 0 is in W.
  2. Addition. Take u = (2s, s, p) and v = (2t, t, q). Then u + v = (2(s + t), s + t, p + q), which satisfies the condition, so it is in W.
  3. Scaling. For any real c, cu = (2cs, cs, cp), which also satisfies x = 2y.
  4. Conclusion. W is a subspace. Its z-coordinate is free, so W is a plane through the origin.

3 · Is {(1, 2), (2, 4)} linearly independent?

  1. Set c₁(1, 2) + c₂(2, 4) = (0, 0). The two coordinate equations are c₁ + 2c₂ = 0 and 2c₁ + 4c₂ = 0.
  2. The second equation is twice the first, so there are solutions other than the trivial one. Take c₂ = 1 and c₁ = −2.
  3. Check: −2(1, 2) + (2, 4) = (0, 0), with nonzero coefficients. The list is dependent.

4 · Is (4, 5, 6) in span{(1, 0, 1), (0, 1, 1)}?

  1. We need a(1, 0, 1) + b(0, 1, 1) = (4, 5, 6), which is (a, b, a + b) = (4, 5, 6).
  2. The first two coordinates give a = 4 and b = 5.
  3. The third coordinate would then be a + b = 9, not 6. No solution exists, so (4, 5, 6) is not in the span.

5 · Show that ℤ/6ℤ is not a field

  1. A field needs every nonzero element to have an inverse. Look at 2: 2 · 3 = 6 ≡ 0 (mod 6).
  2. Suppose 2 had an inverse b, so 2b ≡ 1 (mod 6). Multiply both sides by 3: 6b ≡ 3, which says 0 ≡ 3 (mod 6). That is false.
  3. So 2 has no inverse, and ℤ/6ℤ is not a field.

Why it works: 2 and 3 are zero divisors. A field has none.

6 · Find the remainder of 156,347 when divided by 11

  1. Since 10 ≡ −1 (mod 11), the powers of 10 alternate in sign, so use alternating digit sums, starting from the right.
  2. 7 − 4 + 3 − 6 + 5 − 1 = 4.
  3. So 156,347 ≡ 4 (mod 11). Check: 11 · 14,213 = 156,343, and 156,347 − 156,343 = 4.

Common mistakes

  • Checking a few examples and calling it a proof. A “for all” claim needs an argument that works for every element.
  • Forgetting to check that 0 is in a subspace, or treating the empty set as the number 0.
  • Reading f⁻¹(V) as an inverse function. The preimage is always a set. An inverse function exists only when f is bijective.
  • Testing surjectivity against the domain instead of the codomain.
  • Forgetting to reduce mod m. In ℤ/9ℤ, [3] + [7] is [1], not 10.
  • Calling vectors independent because they look different. Test for a nonzero combination that gives zero.
  • Assuming independence is the same over every field. Over F₂ the same vectors can behave differently from how they behave over ℝ.
  • Confusing spanning with basis. A spanning list can contain redundant vectors; a basis cannot.
  • Assuming every nonzero element of a ring has an inverse. ℤ/6ℤ has zero divisors.

Proof templates

  • To show A = B: show A ⊆ B and B ⊆ A.
  • To show f is injective: assume f(x) = f(y) and deduce x = y.
  • To show f is surjective: take an arbitrary y in the codomain and solve f(x) = y.
  • To show W is a subspace: show 0 is in W, that W is closed under addition, and that W is closed under scaling.
  • To show a list is a basis: show it spans, and show it is independent.
  • To show a ≡ b (mod m): show that m divides a − b.
